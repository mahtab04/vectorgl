01 / CHOOSE YOUR ABSTRACTION

Direct when you want it.
Structured when you need it.

Mix drawing, scene objects and controls in the same application. Each API has a clear job, with a shared OpenGL renderer underneath.

01

Canvas↗

IMMEDIATE MODE

Issue drawing commands each frame. Shapes, paths, text, images and SVG, in the order you choose.

For charts, overlays & custom visuals02

Scene↗

RETAINED MODE

Keep objects alive. Compose hierarchies, inherit transforms and animate properties over time.

For animated scenes & interactive objects03

UI↗

APPLICATION LAYER

Lay out controls, route input and manage focus. Lists, trees, tables and panels, ready to compose.

For inspectors, workspaces & editors

03 / LESS BETWEEN YOU AND THE SCREEN

The code is the interface.

Familiar C++ calls, explicit lifetimes and a CMake target for each module. Start with a shape, then add the structure your application needs.

Pick your starting point.

Canvas for drawing. Scene for persistent objects. UI for input and controls. The examples use the actual public API.

Browse the API reference ↗
canvas.cpp 
// Inside your OpenGL frame.
canvas.beginFrame(fbWidth, fbHeight);
canvas.setFillColor(vectorgl::Color::hex(0xA6E35C));
canvas.fillRoundedRect(24, 24, 280, 140, 18);
canvas.setFillColor(vectorgl::Color::White);
canvas.fillCircle(164, 94, 36);
canvas.endFrame();
scene.cpp 
// Create once, then update persistent objects.
vectorgl::Scene scene(canvas.renderer());
auto card = scene.roundedRect(24, 24, 280, 140, 18);
card->setFill(vectorgl::Color::hex(0xA6E35C));
card->setPosition(80, 60);

// During an active Canvas frame.
scene.render();
controls.cpp 
// Context outlives the controls it owns.
vectorgl::ui::Context ui;
vectorgl::ui::ButtonOptions options;
options.label = "Save document";
options.onActivated = [] { /* Application save hook. */ };
vectorgl::ui::Button save(ui, {}, options);
ui.setBounds(save.id(), {24, 24, 180, 44});

// Forward host input; paint inside a Canvas frame.
ui.dispatch(event);
ui.paint(canvas, viewport);
