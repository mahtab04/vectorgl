VectorGL exposes two complementary layers: Canvas for immediate-mode drawing and Scene for retained-mode composition. Both sit on top of the same Renderer and require an OpenGL 3.3 context. Core Concepts Choose the right layer Getting Started Build, initialize, and render a first frame Build and link VectorGL targets OpenGL 3.3 Core and a C++20 toolchain. Create the OpenGL context first, then initialize Canvas or Renderer only after the context is current.
